# 即時行情與商用授權守門規範

最後更新：2026-09-20

> 本文件是產品與工程檢查表，不取代律師、資料供應商或交易所提供的正式法律意見。

## 不可跨越的規則

1. 未取得明確商用展示或重分發權利的資料，不放進付費會員權益。
2. 延遲、盤後與即時行情必須使用不同標示，不得以更新動畫混淆。
3. API key、簽章密鑰、付款密鑰與會員資料不得放在 GitHub Pages。
4. 新聞只顯示必要的標題、來源、時間、摘要與原文連結；不複製全文、圖片或付費牆內容。
5. 插圖、圖示、字體、照片與背景只使用：
   - 自行創作並保留原始檔與創作紀錄；
   - 明確允許商用的授權素材，保存授權版本與取得日期；
   - 已購買且範圍涵蓋網站、會員制、廣告與衍生宣傳的授權。
6. 「免費可看」不等於「可商用」；免費 API 也不代表允許重分發或放入收費服務。
7. 無法確認時，狀態一律視為「不可收費使用」，不是先上線再說。

## 真正盤中行情目標架構

瀏覽器只連接本站 API，不直接接觸供應商密鑰。

1. 授權行情供應商：提供合約允許的即時報價、分鐘 K 線及使用人數方案。
2. Serverless／後端擷取層：保存密鑰、簽章請求、限流與錯誤重試。
3. 快取與資料庫：保存最新報價、分鐘 K 線、來源時間與授權欄位。
4. 會員權限層：驗證免費／一般／高階會員可讀取的資料範圍。
5. 前端：顯示來源時間、延遲秒數、更新狀態與過期警告。
6. 稽核紀錄：記錄資料來源、轉換方式、API 使用量、同時使用人數及授權版本。

## 更新與失敗規則

- 即時：必須由合約定義允許的延遲秒數與更新頻率。
- 延遲：畫面固定顯示「延遲行情」與最後來源時間。
- 盤後：不得使用「即時」「盤中更新中」等文字。
- 失敗：保留最後成功資料，但固定標示「資料可能過期」。
- 缺值：顯示「尚無資料」，不得以 0 代替。
- 時鐘：資料時間以供應商時間為準，另保存本站接收時間。

## 分鐘 K 線最低需求

- 1／5／15／30／60 分 K。
- OHLCV、來源時間、時區與交易時段。
- 除權息、換日、夜盤與休市規則。
- 斷線補洞、重複資料去除、異常成交檢查。
- 原始資料與衍生指標分開保存。
- MA、壓力支撐與訊號均標示計算版本。

## 商用上線 Gate

- [ ] 書面確認可提供給付費會員
- [ ] 書面確認可保存歷史與製作衍生統計
- [ ] 確認使用者／裝置／請求量計費方式
- [ ] 後端密鑰管理與輪替
- [ ] 登入、付款、權限與退款流程
- [ ] 隱私權政策、服務條款、資料來源頁
- [ ] 圖片、字體、圖示與新聞來源授權盤點
- [ ] 壓力測試、斷線與過期資料演練

## 現階段允許範圍

目前 GitHub Pages 版本只做公開測試、盤後資料與明確標示的延遲資料。全球市場公開端點只作功能原型，不視為未來會員制的既定商用資料源。
