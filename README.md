# 台股 AI 研究站

GitHub Pages 靜態研究站：GitHub Actions 定期取得資料、整理為 JSON、保留歷史快照，再由前端顯示。

> ⚠️ 本站為研究與教學用途，資料不構成投資建議。

## 已完成與持續維護

- 台股搜尋、全部股票、觀察清單與個股詳情
- TWSE 盤後 OHLCV、三大法人、歷史 K 線
- MA5／MA20／MA60 與當日、5 日、近 1 月、3 月、6 月切換
- 壓力支撐 V2、成交量排行、產業紅綠燈、排行日比較
- 主動 ETF 行情、22 檔官方持股、每日變化、共識、連續增減、產業熱力
- 市場、ETF 與個股新聞；新聞只補充事件背景，不取代數據判斷
- 量化研究頁、會員功能分級與未來回測架構

## 全球市場連動雷達

### 免費 V1

- 追蹤 BTC、ETH、NQ、標普 500 期貨、費城半導體、VIX、WTI、黃金、DXY、美國 10 年期公債殖利率
- 顯示價格、漲跌幅、資料時間、延遲／過期狀態
- 全球風險溫度 0～100 與偏多、中性、風險偏好降溫、高風險警報
- 規則式市場分歧判讀、台股可能影響、受影響族群與下一步觀察
- 嚴格分開「已確認數據」「規則訊號」「可能推論」「歷史統計」
- 每小時更新；抓取失敗保留上一筆並標示「資料可能過期」
- 依台灣時間分成盤前、盤中、盤後與休市摘要
- 每次保留歷史快照，為後續回測累積資料

### 後續資料與驗證

- 加入日圓、台指期夜盤與其他台股敏感指標
- 統計訊號後台股隔日、3 日、5 日、10 日表現
- 產業勝率、最大漲跌幅、樣本數與最近相似日期
- 樣本不足時只顯示「樣本不足」，不提供假勝率
- 個股與 ETF 的國際風險曝險將逐步由產業規則升級為財報與成分資料驗證

## 商用與架構原則

目前全球行情免費來源只用於研究站原型與功能驗證，不能把延遲行情標成即時。正式會員制上線前，必須逐項確認商用展示、重分發、衍生分析及即時行情授權，必要時改接付費授權 API。

GitHub Pages 適合公開的盤後與較低頻率資料；真正盤中即時行情、會員登入、付款、權限、自訂通知與付費資料必須移到安全後端，API 金鑰不可放在前端。
